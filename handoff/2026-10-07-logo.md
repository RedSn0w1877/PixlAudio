# Handoff: new launcher icon, logo concept C (October 7, 2026)

Written by Claude (Opus 5.5), branch `awt/logo` from `android-int-oct3`. Not pushed.

Hoa picked logo concept C, "Glyph", as the universal PixlAudio logo for both apps: the old monochrome silhouette
(play triangle, lens cut-out, note) as a white frosted-glass glyph on a sky-to-violet gradient. The iOS port got the
same logo (iOS repo, branch `wt/logo`).

## What changed
- Launcher icon, phone (`app/src/main/res`) and Wear (`wear/src/main/res`): new `ic_launcher_background.webp`
  (gradient) and `ic_launcher_foreground.webp` (glyph and its shadows on transparent) at every density, 108 dp
  (108 to 432 px), lossless WebP as before. `mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml` are
  unchanged and still point at them. The legacy 48 dp `ic_launcher(_round).webp` were regenerated too (unused at
  minSdk 30).
- Themed icon: `drawable/new_monochrome.xml` (phone and Wear) is now the new glyph as a vector, placed exactly like
  the foreground.
- In-app logo: `drawable/pixelplay_base_monochrome.xml` (About, the Play Store announcement dialog, the full-player
  placeholder) is the new glyph, with the old drawable's box margins, so the callers' sizes didn't change.
- `assets/icon.png`: the README icon (it was missing on this branch, so the README image was broken).
- `tools/make-launcher-icon.py` renders all of the above. The logo's geometry lives in the iOS repo's
  `ci/make-icon.py`; run `python tools/make-launcher-icon.py --generator <ios repo>/ci/make-icon.py --preview out.png`.
  The 1024 icon grid maps onto the central 72 dp, so the icon matches iOS. The glyph reaches 27.7 dp from the centre
  (shadow 31 dp), inside the 33 dp safe zone.

## Left as they were
- `drawable/monochrome_player.xml` (the notification small icon) still has the old silhouette, which has the same
  shape family. Redraw it from the generator if the status-bar icon should match exactly.
- `drawable/theveloper_icon.png` is the developer's avatar, not the app logo, and unused; `drawable/monochrome.xml`,
  `ic_launcher_background.xml` and `ic_launcher_foreground.xml` are unused template leftovers.

## Verified
- `./gradlew :app:processDebugResources :wear:processDebugResources --no-daemon --max-workers=2`: BUILD SUCCESSFUL
  (the first try hit Maven Central's HTTP 429 and was retried after 60 s).
- The vector drawables were parsed back and rasterized: they match the icon's glyph to within a fraction of a pixel,
  and `pixelplay_base_monochrome` fills 77 % x 88.5 % of its box, like the old one.
- Previews of the composited icons (circle and squircle masks at 48 dp, themed light and dark, the 108 dp layer with
  the 72 dp mask and the 66 dp safe zone) looked right. Not yet seen on the phone or a watch.
